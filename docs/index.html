How to read this

  • Every number comes from public data (OpenAlex, Wikipedia pageviews, FRED). Each indicator links to its source.
  • Momentum (z) compares the last 12 months of change with the indicator's own history. Above +2 counts as a breakout.
  • Tipping point is where an S-curve fitted to the data is steepest, meaning the change is half done. The range comes from 200 bootstrap refits. If the curve is still in its early, accelerating phase, its timing can't be estimated yet, and the page says so instead of guessing.
  • Wikipedia pageviews measure attention, not change in the world. Labor and production series measure real economic conditions but move slowly.
  • This tests a hypothesis against trends. It isn't a prophecy. Every run is logged in reports/history.csv so its calls can be scored later.
